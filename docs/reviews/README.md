# External reviews

Answers from other models to the review prompt (`docs/DIS_INCELEME_PROMPT.md`). A review is **input, not a rule change**;
what we accept is written into `docs/YOL_HARITASI_v2.md`.

**Rule:** keep a review's original text unchanged in `<name>_original.md`. A translation goes in a separate file
(`<name>_EN.md`). Never translate over the original.

| File | What it is |
|---|---|
| `review_prompt_v1_EN.md` | The English prompt actually given to the models (earlier wording; body kept unchanged) |
| `review_1_chatgpt_EN.md` | Review 1 (ChatGPT deep research). **English translation only** — the Turkish original was overwritten during translation (before this rule). The translation was checked against the original: key figures and all 18 findings match |
| `review_2_original.md` | Review 2, original text as received |
